
## 👋 Hello! I'm Avinash Nandikatti

I'm a Data Engineer with 6+ years of experience building scalable, cloud-native data solutions across Supply Chain, Healthcare, and Finance domains. I specialize in designing resilient data systems, optimizing ETL pipelines, and enabling real-time analytics using tools like AWS Glue, Azure Data Factory, Databricks, Snowflake, and Power BI.

🎓 Currently pursuing my Master’s in Computer Science at the University of Cincinnati, I’m passionate about blending engineering excellence with business impact. My work has consistently reduced data processing time, streamlined reporting, and delivered KPIs that drive decisions.

💡 My recent projects involve:
- Migrating legacy ERP data to modern cloud platforms (Azure, AWS)
- Designing medallion architecture for healthcare RCM analytics
- Building low-latency fraud detection pipelines using Kinesis and QuickSight
- Developing Power BI and Streamlit dashboards used by executives and plant managers

📫 I enjoy mentoring, working on data governance, and creating automation around data quality.
